# Day 04: Number analyzer


Today I build a simple number analyzer python program.


## Features:

- Detects integer or decimal
- Identify sign of the number
- check parity if the number is integer
- Calculate square of the number
- Determine absolute value of the number.

## Concepts practiced:

- user input
- `float()`
- if/elif/else
- Functions
- Modulo operator
- f-strings

## How to run the code:

```bash
python main.py
```

## Example:

Output:
```text
Type any number: -2.5
___Number analysis___
Type: Decimal
Sign: Negative

A decimal number cannot be classified as even or odd.

Square: 6.25
Absolute: 2.5
Thank you for coming!
```
