# Day-06 Student Record Manager

Today i have built simple python **Student Record Manager**. It takes the student details as input and display the stored student record.

## Features

- Takes the user input with empty-list edge case handling
- Performs calculations on student data
- Store the data in dictionary
- Display the stored student record

## Concepts practiced

1. List
2. `.append()`
3. `max()`
4. `min()`
5. `len()`
6. `sum()`
7. for loop
8. `range()`
9. Functions
10. f-string
11. if ,else
12. `float()`
13. Dictionary

## How to run ?

```bash
python main.py
```
