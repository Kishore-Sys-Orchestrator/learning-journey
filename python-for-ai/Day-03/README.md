# Simple Python Calculator

A basic Python program that performs simple arithmetic operations.  
The script asks for two numbers and an operation, then prints the result.

## Features
- Addition
- Subtraction
- Multiplication
- Division (with division by zero check)

## How to Run
1. Install Python (version 3.x).
2. Clone or download this repository.
3. Run the script in your terminal:

python calculator.py
## Example
Enter first number: 10
Enter second number: 5
Choose operation (+, -, *, /): *
Result: 50.0


## Why I Made This
I wanted a simple project to practice Python basics and get familiar with uploading code to GitHub.  
This calculator covers input, conditionals, and arithmetic in one short program.
