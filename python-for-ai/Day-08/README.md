# Day-08 Books manager using file handling

Until Day-7 i have got the inputs from the user and then produced the results. But once i closed the program or IDE the inputs or data gone.
So, today i actually filled that gap by implementing file handling concepts through **Books manager**.

## Features:
- Add a Book
- Remove a Book
- Show All Books
- Search for a Book
- Store Book and Author Details
- Persistent Book Storage
- Interactive Menu
- Continuous Program Execution
- Basic Input Validation
- Invalid Choice Handling
- Updated Book List After Deletion
- Exit Option
