# Day-05 Mark analyzer

Today i have built a **Mark Analyzer**. It does basic mark analysis on the user input and provide the output.

## Features

- Take the multiple numbers as input
- Performs analysis on it such as
    - Total subjects
    - Total marks
    - Average mark
    - Maximum mark
    - Minimum mark
    - Number of subjects passed
    - Number of subjects failed
- It can also handle the edge case of "empty input from user".


```text
Enter the marks with a space between each: 56 78 34 98 12
```
